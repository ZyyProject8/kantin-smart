# Kantin Pintar UI

Saya ingin membuat sebuah website modern bernama Kantin Pintar.

Website ini adalah platform digital yang membantu proses pemesanan makanan di kantin sekolah, kampus, maupun perkantoran.

Fokus pada tahap ini hanya membuat desain UI/UX dan prototype frontend.

Jangan membuat backend.

Jangan membuat database.

Jangan membuat API.

Jangan membuat autentikasi yang berfungsi.

Gunakan data dummy (mock data).

Saya akan mengembangkan seluruh backend menggunakan Laravel pada tahap berikutnya.

Tujuan

Saya ingin website ini terlihat seperti produk startup modern.

Bukan seperti dashboard admin biasa.

Website harus terasa premium, bersih, responsif, dan mudah digunakan.

Gunakan desain minimalis dengan whitespace yang baik, ikon modern, card layout, animasi halus, dan pengalaman pengguna yang nyaman.

Fokus Penting

Jangan membuat website seperti sistem kasir lama.

Saya ingin tampilannya terasa seperti produk startup tahun 2026.

Utamakan pengalaman pengguna dibanding banyaknya fitur.

Pastikan seluruh halaman saling terhubung sehingga saya dapat mengklik dan mencoba alur lengkap dari Landing Page → Login → Dashboard → Pesan Makanan → Checkout → Tracking Pesanan → Riwayat.
